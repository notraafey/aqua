# AquaSentinel Development Guide

Please refer to the complete and up-to-date development guide located at:
[`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md)

### Quick Commands
```bash
# Build all workspaces
npm run build

# Run all unit and integration tests
npm test -- --run

# Run local development servers (Backend: 3001, Frontend: 5173)
npm run dev:all
```
